# Arc default-directory continuation

See [the report](../arc-base-url-2026-11-21.md). The selected ordinary default
constructs user-domain Application Support / Arc / StorableBoostsData.json,
with separate conditional CLI and stored preference overrides. Full Arc,
active runtime selection and durability remain unproved.

Production source and the qualified frozen runtime are unchanged. `mcp/`
retains the initial bounded-profile session (73 calls, four admission errors).
`mcp-seeded/` adds the exact source-verified 18-entry overlay (73/73 replies).
`mcp-string/` binds the concrete default string reader/selector and CLI helper.
All sessions close twice and verify empty lineage.

`prepare_overlay.py` is supplemental query planning. `read_original_plist.mjs`
uses the existing owned read-only DMG reader only to retrieve exact plist
bytes, then public `inspect_plist` owns their interpretation. The byte carrier
and SDK constants are source-bound in the text receipts; the physical plist
stays local and ignored. No executable or profile was run.

`verify_capture.mjs`, `verify_facts.py`, `verify_history.py` and
`verify_snapshot.py` authenticate captures, selected facts, original historical
bytes and the shareable text inventory without reopening a provider. Recreate
Info.plist from `plist-carrier.json` if replaying its public input. The original
DMG/slice, caches and provider projects remain excluded from publication.
